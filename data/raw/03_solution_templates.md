# 典型组合方案模版

本文档给出几类典型客户场景下的投资组合配置方案模版,作为生成新方案与方案优化的
参考范例。每个方案模版为一个独立的语义单元。

## 方案模版 A 保守稳健型组合

- **目标客户**:保守型风险偏好(RP-CONSERVATIVE),短期至中期投资期限,以本金安全为首要诉求。
- **配置组合**:RP-CONSERVATIVE + ASSET-MONEY(35%)+ ASSET-BOND(50%)+ ASSET-GOLD(15%)+ RISK-LIQUIDITY + RISK-MAXEQUITY(上限 20%)。
- **预期效果**:本金稳定性高、流动性强,目标年化收益约 3%。
- **配置要点**:不配置权益类资产与 QDII,不开启杠杆;以货币基金保证流动性,债券基金提供稳健票息,少量黄金对冲通胀。

## 方案模版 B 平衡增值型组合

- **目标客户**:平衡型风险偏好(RP-BALANCED),长期投资期限,追求资产稳健增值。
- **配置组合**:RP-BALANCED + HORIZON-LONG + ASSET-MONEY(10%)+ ASSET-BOND(40%)+ ASSET-EQUITY(30%)+ ASSET-QDII(10%)+ ASSET-GOLD(10%)+ STRAT-DCA + STRAT-REBAL-Y + RISK-STOPLOSS + RISK-MAXEQUITY(上限 50%)。
- **预期效果**:收益与波动平衡,目标年化收益约 6%,最大回撤控制在 10% 以内。
- **配置要点**:权益类资产采用定投分批建仓以降低择时风险;年度再平衡维持比例;设置止损线控制下行。

## 方案模版 C 进取成长型组合

- **目标客户**:进取型风险偏好(RP-AGGRESSIVE),长期投资期限,追求较高收益且能承受较大波动。
- **配置组合**:RP-AGGRESSIVE + HORIZON-LONG + ASSET-BOND(15%)+ ASSET-EQUITY(55%)+ ASSET-QDII(20%)+ ASSET-GOLD(10%)+ STRAT-DCA + STRAT-REBAL-Q + RISK-TAKEPROFIT + RISK-STOPLOSS + RISK-CONCENTRATION。
- **预期效果**:收益弹性大,目标年化收益 8% 以上,波动与回撤显著高于平衡型组合。
- **配置要点**:权益类资产为收益主力;季度再平衡保持纪律;同时设置止盈与止损线;通过集中度限制分散单一资产风险。可按需评估是否开启杠杆融资配置。

## 方案模版 D 养老储备型组合

- **目标客户**:平衡型风险偏好(RP-BALANCED),长期投资期限,以养老储备为目标。
- **配置组合**:RP-BALANCED + HORIZON-LONG + ASSET-PENSION(20%)+ ASSET-INSURANCE(20%)+ ASSET-BOND(35%)+ ASSET-EQUITY(20%)+ ASSET-GOLD(5%)+ STRAT-DCA + STRAT-DIVREINVEST + RISK-LOCKUP。
- **预期效果**:长期复利累积,锁定部分确定收益,流动性较低但收益预期稳健。
- **配置要点**:利用个人养老金账户的税收递延优惠;保险理财锁定长期收益;分红再投资实现复利;因开启长期锁定,本方案不配置流动性保障。

## 方案优化常见场景

- **客户提出需要应急资金**:在长期组合中若客户临时出现用款需求,需评估关闭长期锁定配置、改为开启流动性保障,并相应调整资产比例。
- **客户风险承受能力下降**:将风险偏好由进取型调整为平衡型时,需同步下调权益仓位上限、关闭杠杆融资配置,并复核止损线设置。
- **市场波动加剧**:可在已有权益资产的组合上补充止损线设置,或将一次性买入改为定投策略以降低择时风险。
