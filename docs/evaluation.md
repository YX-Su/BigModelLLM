# 测评体系

为全面衡量智能配置助手的效果,设计两层测评体系:**过程指标**评估系统本身的能力,
**结果指标**评估业务落地后的真实效果。

## 第一层:过程指标

聚焦系统各模块的能力,可通过 `scripts/evaluate.py` 自动计算。

### 1. 意图识别准确率

- **口径**:意图识别模块对测试集查询的分类结果与人工标注一致的比例。
- **测试集**:`data/eval/intent_testset.json`,覆盖 explain / generate / optimize / invalid 四类。
- **运行**:`python scripts/evaluate.py --intent`(纯规则路径,无需外部服务)。
- **参考目标**:≥ 98%。

### 2. RAG 检索召回率(图谱前后对比)

- **口径**:对测试集查询,检索结果覆盖到的"标准配置项"占全部相关配置项的比例。
  - **基线召回率**:仅使用纯向量检索(无知识图谱)。
  - **GraphRAG 召回率**:使用完整的两阶段 GraphRAG 检索。
- **测试集**:`data/eval/retrieval_testset.json`,每条查询标注其相关配置项编码。
- **运行**:`python scripts/evaluate.py --retrieval`(需启动 Milvus / Elasticsearch / Neo4j)。
- **参考目标**:基线约 70%,引入图谱后提升至 95% 左右。
- **图谱增益来源**:依赖 / 互斥关系类查询(如"季度再平衡需要什么前提")中,纯向量
  检索易漏召回被依赖的配置项,而图谱的 1~2 跳扩展可稳定补全相关实体。

### 3. 大模型生成任务准确率

- **口径**:生成的配置方案同时满足以下条件的样本占比:
  - 必含配置项(`must_codes`)全部出现在方案中;
  - 禁止配置项(`forbidden_codes`)均未出现;
  - 方案通过规则系统的依赖 / 互斥校验。
- **测试集**:`data/eval/generation_testset.json`。
- **运行**:`python scripts/evaluate.py --generation`(需存储栈 + 可用的 LLM 接口)。
- **参考目标**:≥ 95%。

### 4. 指令遵循率

- **口径**:输出格式与内容对一线顾问是否友好、可直接使用,属主观指标。
- **采集方式**:由内部人员对生成结果打分调研,不纳入自动测评。
- **参考目标**:≈ 98%。

## 第二层:结果指标

聚焦业务落地后的真实效果,需结合线上运营数据统计:

- **配置耗时对比**:人工配置 vs. 系统辅助配置完成一套方案的平均耗时。
- **线上错误配置修复率**:上线后因配置错误产生的问题数量的下降幅度。
- **新人上手时间**:新顾问独立完成合规配置所需的培训时长。
- **业务赋能效果**:助手覆盖的配置场景占比、顾问满意度等。

> 参考口径:配置方案耗时由约 10 分钟降低至 2~3 分钟;配置错误相关问题减少约一半。

## 一键测评

```bash
python scripts/evaluate.py --all
```

未启动存储栈或未配置 LLM 时,需要外部依赖的测评项会自动跳过,仅输出意图识别准确率。
